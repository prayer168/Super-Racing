# 超級賽車 Super Racing

純前端、單檔 HTML5 的「車流穿梭」賽車小遊戲（Traffic Racer），無需安裝、開瀏覽器即玩，電腦與手機皆支援。

▶️ **線上試玩：** https://prayer168.github.io/Super-Racing/

## 玩法
- `← →` 變換車道、`↑` 油門、`↓` 煞車、`空白鍵` 氮氣
- 手機：左右按鈕變換車道、按住 NITRO 加速
- 貼著別的車閃過 = **Near Miss** 加分；吃金幣、別撞車

## 特色
- 2.5D 透視道路，會隨機彎曲
- 即時合成音效（引擎／煞車／撞車／金幣）
- Nitro 能量條、撞車爆炸特效
- 金幣永久存檔 + 車庫換車／解鎖（5 台車，各有性能差異）
- **11 個世界地景場景**循環：大峽谷、張掖丹霞、喜馬拉雅、冰島冰川火山、撒哈拉、死亡谷、黃石、亞馬遜雨林、太魯閣、阿里山雲海、墾丁海岸
